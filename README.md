# What the Body Remembers

Medicine, War, and Care in Lebanon — a working digital exhibition of CHLA 215 student multimedia work.

Static website: HTML, CSS, and JavaScript. Content is edited in `content.js`; layout and behavior in `app.js` and `style.css`.

For GitHub Pages, publish from the main branch and root folder. Keep the assets folder alongside index.html.

This is a working catalogue with missing materials clearly marked. Credits, statements, permissions, venue and dates still require final verification. No reuse licence for student artworks is granted by this repository.

Flashbulb Memory is the photography section at #photographs. Its final records and exact series statement are defined by EXHIBITION.photographs and EXHIBITION.photography at the end of content.js. Each photo has a stable id, plate, movement, title, caption, alt description, optional badge, and two image sizes. Keep the source image proportions. The series statement uses explicit paragraph and emphasis markup to preserve the approved formatting. #the-body-remembers remains Seungju Moon’s podcast. Individual photo statements have not been invented; photograph views link to the supplied series statement.
