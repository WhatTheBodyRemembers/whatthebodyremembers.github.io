# What the Body Remembers

Medicine, War, and Care in Lebanon — a working digital exhibition of CHLA 215 student multimedia work.

Static website: HTML, CSS, and JavaScript. Content is edited in `content.js`; layout and behavior in `app.js` and `style.css`.

For GitHub Pages, publish from the main branch and root folder. Keep the assets folder alongside index.html.

This is a working catalogue with missing materials clearly marked. Credits, statements, permissions, venue and dates still require final verification. No reuse licence for student artworks is granted by this repository.
